## 四、3TB 流量和 1Gbps 端口，别当成两个保证

1Gbps 是端口速率，也叫端口带宽。它说明这台机器网卡协商到千兆，不说明你任何时候都能跑出千兆。实际能到多少，取决于机房当时的负载、你的对端线路和服务商在上游的拥塞控制。促销公告本身也写了这一层限制。

流量则是另一套口径。RackNerd 给的是每月 3TB 到 12TB，按月重置。需要在下单前问清楚的有两点：

第一，流量怎么统计。只算公网出方向，还是进出都算？做图床、做下载站、做视频转发的场景，两种算法的结果能差一倍。

第二，超了之后怎么处理。业内的做法五花八门，有的按 GB 额外计费，有的直接限速，也有像部分低价商家那样把带宽压到 1Mbps 等次月 1 日重置。RackNerd 这轮促销页没有写超限规则，年付之前问一句，比事后看账单划算。

3TB 月流量对个人博客、企业展示站、跨境后台是够用的。跑 24 小时不间断上传下载，或者拿来当中转节点扛大流量，这个额度撑不到月底。

## 八、几个常被问到的问题

### 美国 VPS 需要备案吗？

不需要。美国机房不在 ICP 备案管辖范围内，开通就能用。

### 国内访问延迟大概多少？

这轮促销没有公布统一测试 IP 或 Looking Glass，所以任何精确到毫秒的“RackNerd 延迟”都缺依据。可以给你两个量级参考：同为洛杉矶的普通线路，第三方测评给出的国内 ping 在 130–160ms 区间（Evoxt 洛杉矶节点的测评数据）；走 CN2 GIA 的商家，官方口径是 120–180ms。这两个数字都不是 RackNerd 的实测值，只能当作同类线路的参考量级。想精确判断，唯一办法是找已经买到的人要个 IP，或者自己开最低档测一周。

### KVM 套餐多久开通？

第三方站点的说明是下单完成后即时开通，KVM 套餐自动部署。真遇到需要人工审核的订单，工单问一下进度就行。

### 25 端口封不封？

有用户在第三方评价里提到这家不封 25 端口，还提到改 rDNS 记录十分钟内就处理完了。这类用户说法对要发注册信、通知邮件的站点很有价值，但建议自己先用小号验证一遍再迁站。
